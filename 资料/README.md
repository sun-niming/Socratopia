# 翁法罗斯与提瓦特资料库

本目录保存用于制作 Socratopia 人物模板和世界模板的本地资料。正文来源于公开的 BWIKI 页面；每份本地文本都保留来源地址、抓取时间、用途、核验状态和原始 HTML 的 SHA-256。

## 目录结构

```text
资料/
├─ README.md
├─ 索引/
│  ├─ 总索引.md                 逐条列出本地文件与原始网址
│  ├─ 人物模板索引.md           按人物模板字段组织
│  ├─ 世界模板索引.md           按世界模板字段组织
│  ├─ 来源索引-BWIKI.md         按来历、游戏和资料类型组织
│  ├─ 精选来源.json             机器可读的来源清单
│  ├─ 下载清单.json             含本地路径、抓取状态与哈希
│  └─ 储备书目/                 尚未全部下载正文的完整书目地址
├─ 来源原文/BWIKI/              下载的原始 HTML，供复核
├─ 可用文本/                    从原始 HTML 提取的 Markdown 文本
└─ 工具/下载并整理.py           可重复运行的归档工具
```

“人物模板索引”和“世界模板索引”是用途入口；文件实体只在“来源原文”和“可用文本”中保存一份。一个来源同时适用于人物和世界时，两个用途索引会指向同一个文件。

## 使用顺序

1. 先在人物或世界模板索引中选择来源。
2. 平时使用“可用文本”中的 Markdown；需要确认表格、脚注、上下文或页面声明时打开对应原始 HTML 或原始网址。
3. 把一条资料写入模板时保留来源 ID、网址、剧情截止点、叙述者及事实性质。
4. 标为“目录已提取，正文待核验”的资料，即使已经下载，也要读过相关正文后才能写进模板。

本地 Markdown 是自动提取的检索文本，保留主要可见文字，但不保证复现网页排版、折叠结构和脚注跳转。人物模板不要直接导入战斗倍率、配装和材料消耗；世界模板不要把小说、传说、宣传材料或单一人物陈述直接当成客观历史。

资料整理日期与抓取结果以“索引/下载清单.json”为准。原网页可能继续更新；重新抓取时运行：

```bash
python3 资料/工具/下载并整理.py --refresh
```

页面内容及图片的权利和转载条件以原页面声明为准。本目录保留原网址用于本地研究、核对和归属说明，没有下载网页引用的图片、视频、字体或站点脚本资源。
