更新日期：2026-09-15。适用世界：翁法罗斯、提瓦特。

本次按“资料能填入哪个模板字段”筛选已有来源，并保留网页地址。核心页面沿用前次阅读结果；未调用 kimi-webbridge，也未重新逐页联网核验。候选书目仅按目录标题和体裁做初筛，不能据此认定正文内容。

## 两套模板共用的来源规则

一条资料可以服务两种模板，但要拆成具体事实或证据：人物行为归人物，事件因果归历史，社会规则归世界。

- **事实证据**：官方游戏内角色故事、对话、任务和文书；通过社区镜像读取时，同时记录镜像地址与原始任务/书籍名。
- **整理导航**：世界设定页和社区编年史用于建立目录、定位原文；保留引文，不把编辑者推断改写为官方事实。
- **叙述视角**：书信、神话、传说、小说、宣传材料都保留说话者和文体；适合表达信仰、文化或人物态度，不能一律当作历史事实。
- **暂缓进入核心模板**：战斗倍率、配装、抽卡建议、材料消耗、纯解谜步骤、同人推测、无来源结论。世界内真实能力可单独提炼，不能由战斗机制直接推导剧情实力。

## 人物模板：字段与证据

| 模板字段 | 优先使用的资料 | 提炼方法 |
|---|---|---|
| 身份、别名、阵营、职责 | 角色档案、角色故事、明确对话 | 别名和身份附生效阶段；隐藏身份不自动成为所有人已知信息 |
| 性格与价值观 | 角色故事、关键任务选择 | 用可重复观察到的行为支持描述，避免只堆形容词 |
| 核心动机与冲突 | 主线、个人任务、书信 | 分长期追求、当前目标、顾虑与底线 |
| 说话方式 | 日常语音、剧情对话、私人留言 | 提炼称呼、语气、句式、幽默、情感表达，避免整段复制台词 |
| 人物关系 | 双方“关于某人”语音、共同任务 | 关系有方向、有阶段；单方评价不代表客观事实 |
| 重要经历与当前状态 | 角色故事、任务、编年史 | 只收录设定截止点之前已经发生的经历 |
| 知识边界 | 剧情揭露顺序、亲历或听闻证据 | 分本人知道、听说、误解、不知道；读者知道不等于角色知道 |
| 与用户相处及教学方式 | 上述性格与动机 + 用户设定 | 单独标记“苏格拉底适配”，不可冒充原作设定 |

材料使用顺序：角色档案/故事 → 日常语音 → 关键剧情行为 → 双向关系 → 私人文书。NPC 使用任务与对话补足，无独立档案时不虚构年龄或身世。

## 世界模板：字段与证据

| 模板字段 | 优先使用的资料 | 提炼方法 |
|---|---|---|
| 世界前提与规则 | 世界设定页、主线揭露、原始文献 | 区分客观设定、公众信仰、秘密和争议说法 |
| 地理与场所 | 地区设定、任务、游记 | 为地点记录所属、功能、可到达性和剧情阶段 |
| 历史事件 | 专题编年史 + 对应任务/文献 | 每条记录时间、地点、参与者、原因、结果和来源；不强行补精确年份 |
| 组织与权力结构 | 国家/城邦设定、组织文书、任务 | 记录职责、目标、成员和相互关系 |
| 社会生活 | 历法、货币、节庆、职业、饮食文献 | 支持日常互动和场景，避免只有宏大历史 |
| 关键人物与势力分布 | 角色/NPC目录与人物档案 | 世界保存摘要与人物ID，细节留在人物模板 |
| 开场时点与现状 | 指定主线进度和地区任务状态 | 人物是否在场、城市状态、事件结局均依此裁剪 |
| 叙事边界 | 上述来源 + 用户偏好 | 原作事实、未知事项、苏格拉底新增设定分别标记 |

翁法罗斯应特别记录历史阶段、循环/进程与当地人的认知范围；提瓦特应分别记录全大陆背景和各国/地区的剧情进度。两个世界各自维护模板。

## 建议的可追溯结构

每条事实用来源ID关联到本目录，不只在整篇文末堆链接：

```text
事实ID：
所属世界／人物：
填入模板字段：
内容摘要：
性质：原作明示／人物陈述／社区整理／推测／苏格拉底适配
剧情截止点：
谁知道此事：
来源ID与完整URL：
原始角色故事／任务／书籍名：
具体章节或对话位置：
是否已读正文：
冲突来源及处理：
```

人物模板建议章节：身份 → 当前状态 → 性格与动机 → 语气 → 关系 → 经历 → 知识边界 → 苏格拉底互动适配 → 来源。

世界模板建议章节：世界前提 → 规则 → 地理 → 历史 → 组织 → 日常生活 → 关键人物 → 开场状态 → 叙事边界 → 来源。

这些是整理字段建议，尚未声明为应用可直接导入的格式。当前安装包支持独立人物 persona 与世界 story；最终写入前应按应用实际格式适配。
