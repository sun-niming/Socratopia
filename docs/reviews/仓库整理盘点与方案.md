2. `win-unpacked/resources/app.asar`（快照的自洽对之一）被跟踪、根部 `resources/app.asar` 被忽略——符合「快照自洽」设计，但意味着每次刷新快照都是大 blob 提交，是 `.git` 457 MB 的主要来源之一。

### 4.3 历史密钥取证

- 全部 86 个提交的文件名扫描（`git ls-tree -r` 全历史去重）：**没有任何名为 `settings*.json` / `set*.json` 的配置文件进入过历史**（仅命中无关的 `agent-task-datasets/**/1045_set与multiset.json`、`mobile/**/settings.ts` 等）。
- 内容面抽查：`git grep -i 'api_key' $(git rev-list --all) -- 'resources/*.json'` 全历史无命中。
- **结论**：与 README（2026-10-22）「历史上没有提交过真实 key」一致；**CLAUDE.md 第 169 行「That key is still in history from before these rules landed」已过时**，建议改为「全历史无密钥文件记录（2026-11-03 全量文件名+内容核查）」。残留风险：`outputs/account-backups/runtime-config-20260829-2353/` 与磁盘上 `resources/settings*.json` 副本持有**现役 key**，仓库若加 remote，这些文件虽不入库也要确认本地无泄露渠道。
