状态：`SWC-001-A` 产出。判据日期：2026-09-21。  
策略来源：使用者 2026-09-20 选定"证据优先"——只从 `资料/` 已有原始证据的角色里选，不足 8 人时按目录补抓并把缺口记入本文件与 `06`。  
上游：`05-canon-cutoff-schemes.md`（截止点轴）；`02-data-and-prompt-contracts.md`（角色 id 与卡片字段）。

## 1. 判据

"有证据"不等于"被提到"。本文件按三级计：

| 级别 | 判据 | 可用于 |
|---|---|---|
| A 专属 | 该角色有 `人物档案`／`人物语音` 页 | 身份、性格、语气、原著名关系 |
| B 专题 | 该角色在一篇 `世界文献`／编年／设定里被实质叙述（非导航噪声、非仅列名） | 经历、立场、知识边界 |
| C 提及 | 只在 `人物目录`（`S003`／`S013`）或别人的档案里被列名 | 仅够占位，不足以写模板 |

A 级证据决定名单；B 级补经历；只有 C 级的候选占位会被降级或在名单里标注缺口。

选取理由：四人分属璃月／须弥／枫丹／稻妻，且**四人对"神性与身份"的关系各不相同**——`S049` 字段给出纳西妲种族为「草木化身（世界树最纯净的一枝）」、本名布耶尔；`S051` 字段给出芙宁娜种族为「人类」；`S053` 承「御建鸣神主尊大御所」之名而实为人偶代行；钟离是退位长生种。这对 `D004` 的知识权限与秘密边界是有区分度的样本。

`raiden_shogun` 另有一处值得单列：`S053` 人物考据明确「巴尔明面上是初代魔神，但在暗中已经更迭一代了，目前是第二代雷神」，且雷神之名由巴尔、巴尔泽布与人偶三者共用，"民众认知中雷神一直由雷电将军担任"。同一个名字在档案、语音与民众认知里指向不同主体，是首版最直接的一道知识边界测试。

**五名新取证角色都有一个"公开名 ≠ 本名"的裂口**，恰好是身份类知识边界的现成样本：那刻夏/阿那克萨戈拉斯（`S045` 原话「别叫我那刻夏！」）、万敌/迈德漠斯（`S047`）、纳西妲/布耶尔（`S049`）、芙宁娜·德·枫丹（`S051`）、雷电将军/巴尔·巴尔泽布（`S053`）。写模板时必须分列公开称谓与真实身份，并按 `D004` 决定谁知道哪一层。

## 4. 与卡片契约的接口

- 角色 id 用 `02` 已有的小写形态（`phainon`／`aglaea`／`zhongli`），世界内自洽且不与运行时 `worldId`／`profileId` 混用。
- 卡片 `characters` 字段引用这些 id；`knowledgeScope` 按 `D004` 在排名之前过滤。
- 本文件只定身份与证据，不写模板正文——模板与知识卡属 `SWC-001-B`。
- 名单落在 `resources/bundled-content/<lang>/world-lore/<canon>/`（`D009`）时，`<canon>` 用本文件的 `amphoreus`／`teyvat`。
