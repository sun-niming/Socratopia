# 两世界剧情截止点表达体系梳理

状态：阶段 A 前置产出；`SWC-001-A` 已补齐两轴实现与使用者决定。基线日期：2026-09-18。  
配套实现：`resources/server/lib/world-lore/version-order.js`、`version-order-smoke-test.js`。  
证据目录：`资料/`（`资料/索引/下载清单.json` 是来源权威清单）。

## 1. 为什么必须先分开梳理

`02-data-and-prompt-contracts.md` 最早的示例是 `"canonCutoff": "3.4"`，并按 `spoilerLevel` + `timeRange` 双重约束截止点。这个示例对翁法罗斯成立，直接套到提瓦特就会失真；两个世界连"进度"用什么轴表达都不一样。所以先把两边的真实结构分别写清楚，再决定比较函数支持哪条轴。

第 2、3 节只记录**从 `资料/` 可核实的结构事实**；第 5 节起是已确定的契约，决定来源见第 6 节。

## 2. 翁法罗斯（《崩坏：星穹铁道》）

进度在资料里有四条互不相同的轴：

| 轴 | 例子 | 出处 |
|---|---|---|
| 游戏幕（行星级） | `第四幕•翁法罗斯` | `S008_开拓任务`（列有序幕、第一幕…第五幕） |
| 游戏版本 | `3.0` … `3.7` | 全站文本中大量出现；剧情节点的通行表达 |
| 世界内时间 | `光历 3867年`、`光历 4919年` | `S002_翁法罗斯编年史`（48 处年份） |
| 循环序号 | `第 33550336 次永劫回归`、`第 15 次永劫回归` | `S002_翁法罗斯编年史` 的顶层目录 |

`S002` 的组织方式是**循环 → 世界内时期 → 光历年份**，例如：

```text
2 第33550336次永劫回归
2.1 造物世 / 2.2 黄金世 / 2.3 纷争世 / 2.4 幻灭世
3 第33550337次永劫回归
3.3 第一次逐火之旅 / 3.4 第二次逐火之旅
```

结论：翁法罗斯的"截止点"最自然、最可检索的表达是**游戏版本号**；`光历` 与 `循环序号` 是世界内叙事时间，用于让角色说话时自洽，不适合当过滤键（同一版本内世界时间会跨越数千年）。

## 3. 提瓦特（《原神》）

提瓦特没有与翁法罗斯对应的行星级"幕"。它的进度轴是**章·幕**：

| 轴 | 例子 | 出处 |
|---|---|---|
| 游戏章节·幕 | `序章 捕风的异乡人`、`第三章 第六幕 卡利贝尔`、`第六章 空月之歌`、`空月之歌·第九幕`、`间章` | `S017_魔神任务` |
| 游戏版本 | `1.x` … `6.x`（"空月之歌"是第六章对应的版本档） | `S017` 等 |
| 世界内相对时间 | `约6000年前`、`3700年前`、`约2600年前`、`太古`、`不知多久以前` | `S012_提瓦特编年史` |

`S012` 的组织方式是**相对纪元**（太古／葬火之战／降下天钉／坎瑞亚…），不是绝对年份：原文明确保留"约"这类不确定性。

结论：提瓦特的"截止点"既能用版本号，也能用"第X章·第X幕"表达。用幕表达对玩家更可理解（玩家记得的是剧情进度而不是版本号），但它**不是数字**，v1 的版本比较函数无法直接处理。

## 4. 两世界的差异结论

1. **轴不同**：翁法罗斯的可行轴是版本号；提瓦特的可行轴是章·幕 + 版本号。首版因此实现两条轴并按 canon 命名空间隔离，而不是把提瓦特压成版本号（见 5.2 的取舍）。
2. **不可跨界比较**：`3.4` 是星铁的版本，提瓦特的版本已经到 `6.x`；同一个字符串 `3.4` 在两个世界含义无关。任何比较必须先确认 canon 相同，否则只能返回"不可比"，不能返回一个大小。
3. **目录编号会被误认成版本号**：`S002` 编年史目录里有一节叫 `3.4 第二次逐火之旅`，它跟游戏版本 `3.4` 只是数字巧合；同理提瓦特文本里能扫出 `9.4`、`8.2`、`1.7` 这类其实是书目/目录编号的 token。**朴素地用 `\d+\.\d+` 正则抓取一定会误判**，必须附带来源与轴。
4. **世界内时间不参与过滤**：`光历` 年份与"约 N 年前"都是叙事时间，用于措辞，不做截止点判定。

## 5. 首版契约

`version-order.js` 现在实现**两条轴**，均按 canon 命名空间隔离：

| canon | 轴 | 值形态 |
|---|---|---|
| `amphoreus` | `hsr-version` | `3.7` |
| `teyvat` | `genshin-chapter-act`（对外表达） | `第六章·第九幕` |
| `teyvat` | `genshin-version`（版本下界） | `5.8` |

共同规则：

- `null` / `undefined` / `""` 解析为**无界**（+∞），对应卡片契约里 `timeRange.from = null`（自最初）与 `to = null`（无上限）。
- 版本轴缺失分量补 0：`3.4` 与 `3.4.0` 相等。这修掉字符串比较把 `3.10 < 3.4` 判反的错误。
- 非本轴的输入**抛出明确错误**，不静默降级为字符串比较。
- 跨 canon 比较返回 `{comparable:false}`，不返回大小。
- 同一个 canon 上两轴并存也不互相比较：`compareScoped("teyvat","teyvat","第六章·第九幕","5.8")` 返回 `comparable:false`，由调用方显式给出轴名或使用 `axisOfValue` 判定。

### 5.1 提瓦特章·幕轴的编码（全部有出处，不是猜的）

`S017_魔神任务` 给出完整解锁链，编码据此确定：

| 编码对象 | 取值 | 出处 |
|---|---|---|
| `序章` | 章 0 | `序章 捕风的异乡人`、`序章·第三幕巨龙与自由之` |
| `第<中文／阿拉伯数字>章` | 章 N | `第一章` … `第七章 无神怜爱的雪国` |
| `空月之歌` | 章 6 | `- 8 第六章 空月之歌`（别名，同一目录段） |
| `序奏` | 幕 0 | `空月之歌 序奏归途` |
| `第N幕` | 幕 N | `空月之歌 第一幕` … `第十幕虚空劫灰往世书` |
| `间章第K幕` | 章 K、幕 `INTERLUDE_ACT`(100) | 见下 |

`间章第K幕` 的锚点是**第 K 章全部正幕之后、第 K+1 章之前**，由解锁前置推出：

- `完成第一章第三幕后解锁间章第一幕`
- `完成第二章·第四幕回响渊底的安魂曲的情况下会依次解锁并接取`（间章第二幕）
- `完成第三章第五幕、枫原万叶传说任务第一幕陌野不识故人后可接取间章第三幕`
- `完成间章第三幕倾落伽蓝、阿贝多传说任务第一幕旅行者观察报告后可接取间章第四幕`

前三者符合"第 K 章末幕"模式；**K=4 是唯一一处推断**：它的前置是 `间章第三幕` 而非 `第四章` 末幕，但章 4 是唯一既不与间章第三幕同槽、又排在它之后的取值。K=4 因此锚到章 4，而不是给每幕单独维护放置表。

另外两条编码约束：

- **章与幕都不可省。** `第三幕` 单独出现时章未知（每章都有第三幕），`间章` 单独出现时锚定章未知，两者都抛错而不是猜。
- **幕名后缀忽略。** `第九幕身土坏空`、`第一幕死魂灵的夜曲（系列任务）` 里的名字不携带顺序信息，解析后丢弃；分隔符 `·` 与空格同样先归一化掉，`第六章·第九幕` / `第六章 第九幕` / `第六章第九幕` 等价。

### 5.2 两轴如何配合（对外章·幕，机器版本下界）

提瓦特按玩家可理解的**章·幕**表达截止点，同时每条知识与卡片保留版本下界，供过滤与对齐：

- 世界 `manifest.json` 的 `canonCutoff` 是对象：`{"axis":"genshin-chapter-act","value":"<章·幕>","versionFloor":"<版本>"}`。
- 卡片 `timeRange` 用章·幕，是展示与叙述用的表达；
- 卡片同时带版本区间字段，与 `versionFloor` 同轴比较，这条路径只用版本轴，不跨轴推断。
- `versionFloor` 必须由使用者给出：章·幕与版本之间**没有**可从资料直接导出的函数关系（`空月之歌版本` 只在文本里作为整体出现），首版不内置映射表。

## 6. 已确定与仍未决

已由使用者确定：

- 翁法罗斯 canon cutoff：**`3.7`**（`资料/` 中出现的最高版本；2026-09-27 确认它同时是翁法罗斯篇剧情终章「成为昨日的明天」，属故事边界而非"当前最新版本"，星铁最新已发布约 4.5 见 `08` V5）。
- 提瓦特 cutoff 轴：**章·幕为主 + 版本下界**（本文件 5.2）。若改回纯版本号，可直接用 `genshin-version` 轴，不需要章·幕解析。

2026-09-27 按证据回填（`08` 第一部分，使用者可推翻）：

- 提瓦特 `canonCutoff.value` = **`第七章·第二幕`**（死魂灵的夜曲），`versionFloor` = **`7.0`**——资料覆盖到的最新一幕；7.1（2026-09-23 发布）未覆盖。
- 世界内时间（`光历`、相对纪元）**保留为 `worldTime` 注释字段**，不进入过滤与比较；两世界取值格式不同且不可换算（见 `资料/索引/提瓦特历法与时间表达.md` §4）。
- 章·幕 → 版本对照表已由 67 个任务页的「所属版本」字段实测生成（`08` V3）；空月之歌各幕版本名为「月之 N」，**`genshin-version` 轴解析不了它**——相关卡片的版本下界要么扩展解析器、要么只走章·幕轴。
- 已知编码冲突：`间章第四幕`（悖理）实测版本 5.6，真实位置在第五章后段，与 D013 的 K=4→章 4 锚定冲突；cutoff 在第七章不受影响，5.3–5.7 区间的卡片 `timeRange` 需人工校正。
