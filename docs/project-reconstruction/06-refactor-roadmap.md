## 0. 总原则

1. **先止血，再重构。** 当前最贵的不是架构，而是**改动没有保护**（R-02/R-05）。任何代码重构在没有版本控制与验证覆盖前做，都会加大混乱。
2. **区分"能改"和"该改"。** 238 个 `lib/` 文件是手写源码，可当普通代码处理；真正的难点在 **22 个被改写的本体编译产物 + 前端 5 包 + Electron 双副本**。
3. **不假设重建构建链路可行**（Q-021）。它是选项，不是前提。
4. **每步可独立回滚、独立验收。**
5. **先做"权威标记"，再做物理搬迁。**

### 建议的批次顺序（总览）

| 批次 | 主题 | 内容 | 依赖 |
|---|---|---|---|
| **P0** | 止血 | 纳入版本控制、矩阵覆盖 `.next`、补 tracking | 无 |
| **P1** | 修当前可复现缺陷 | BUG-0009/0010/0011/**0012** | P0 |
| **P2** | 加保护网 | 挂载自检、指令文件合一、文档数字校验 | P0 |
| **P3** | 同步机制自动化 | 5 包/8 处 64092/5 处 helper 的一致性校验 | P2 |
| **P4** | 结构与职责 | 巨石拆分、缓存抽象、接线审计 | P3 |
| **P5** | 架构（需立项） | 重建构建链路评估 / 前端机制简化 | P4 |

## 类别 A — 文档与知识组织

### A1 把未跟踪的关键材料纳入版本控制 【P0】
- **问题**：12 份根目录文档 + `tools/` + `outputs/` + `角色/` + `PROJECT_MATH_SPEECH_DOSSIER/` 全部未跟踪（E-352/E-093）。
- **影响**：一次误操作即永久丢失；已发生过同类事故（`06c0256` 删掉两份唯一史料）。
- **目标与范围**：把这些路径加入 git；调整 `.gitignore`（注意 `resources/rules/*` 白名单问题一并处理）。
- **前置依赖**：无。须先确认不含密钥（`settings*.json` 已忽略）。
- **风险与工作量**：`S`。风险极低，唯一注意点是仓库体积（`outputs/` 含 csv/图片）。
- **验收条件**：`git status --short` 中不再出现上述路径为 `??`；`git ls-files` 能查到 `CLAUDE.md`、各 `*_CHANGELOG.md`。
- **回滚**：`git rm --cached` 回到现状。
- **优先级理由**：**最高**。零代码风险、收益立竿见影，且是后续一切工作的前提。
- **依据**：R-02、E-093、E-157、E-352。

### A2 两个指令文件明确主从 【P0】

- **前置依赖**：无。
- **风险与工作量**：`S`。
- **验收条件**：两份文件不再存在互相矛盾的陈述；失效的 `Socratopia_2.0` 路径被修正或标注。
