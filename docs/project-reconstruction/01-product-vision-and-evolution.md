## 1. L1：产品本体愿景（已证实，一手材料）

**来源（E-110）**：`resources/bundled-content/zh/initial_world/world_preset.md`（68 行，随包只读种子内容；`en/` 与 `zh-TW/` 有对应副本）。
**这是目前在仓库中找到的、唯一完整的原始产品叙事。**

### 1.1 要解决的问题

> 一个"价值十亿美元的问题"：
> "在教学环境下，什么是人类出于天性最高效的学习方式？" —— 被称为**天性教育法之问**。"评审委员会每年审阅全球提案，但这个问题至今还没有找到公认的答案。"

### 1.2 核心洞察与主张

> "让自己最快最深掌握知识的，不是课堂、家教、书本或 MOOC —— 而是某个真心信任的朋友，在思而未得的时候问一句：**「你为什么这么想？」**"

> 公式：**伙伴 + 苏格拉底 = 3X · 3A**
> - `3X`：学习效率，达到听课的三倍
> - `3A`：学习的吸引力，与 3A 游戏相当

### 1.3 目标用户（原文明示）

> "让全世界的孩子、学生、学者、终身学习者都享受堪比 3A 游戏的学习动力和三倍的学习效率。"

包含四个层级：孩子 / 学生 / 学者 / 终身学习者。**不是应试提分产品**——原文对比对象是"课堂、家教、书本、MOOC"。

### 1.4 产品所设定的核心体验（用户作为"学习者"）

- 主角（"学习者"）买下一幢大学旁的别墅命名为**苏格拉底实验室**，招募同住者参加学习实验。
- 九人通过筛选考试，最终 1~3 位入住成为"合伙人"。
- **世界基调**（原文）："热忱的、日常的、带一点创业者气质的同居生活"；"角色之间像真正的室友——有默契，也有小摩擦"；"允许闲聊和跑题，但最终会自然回到学习上来"。
- 交付的是**陪伴感 + 苏格拉底追问**，而非课程表。

### 1.5 成功标准（原文）

> "如果成功，奖金属于所有人，而答案属于全人类。"

即：目标是**回答"天性教育法之问"并把学习法传播出去**，而不是商业指标。

### 1.6 与 L1 一致的产品形态

- 随包候选角色 9 位（`bundled-content/*/initial_world/candidates/`：alice、holmes、huo_yunlai、lu_yumeng、meng_xu、qiu_lingni、sun_wukong、tao_li、wen_ying + `world_preset_blank.md`）→ **正是"九人"设定**（E-111）。
- `zh` / `en` / `zh-TW` 三语齐备 → 面向全球。
- 语音：伙伴用 TTS 讲话（E-112）。

> **待确认**：L1 是否属于原始团队而非本分支。**合理推断**为本分支之前即存在，依据：位于 `bundled-content`（随包种子，非用户数据）；叙事描述的是产品级设定，不涉及本分支新增的自适应/练习/精读能力。**未证实**（`bundled-content/` 被 gitignore，无提交史可查）。

## 2. L2：魔改分支的目标（已证实，自述）

`recovered/RENAME.md`（E-080）自述其方向是把应用扩展成带以下能力的学习系统：自适应教学、教材知识图谱、出题练习、教学进度锚定、PDF 精读、多知识源检索、长推理检查、课后记忆、本地语音优化。

`RECOVERED` 中的一段直接给出 L2 的隐含前提：
> "这条分支的演进路线并不是'推倒重写'，而是在一个已经封装好的桌面应用上不断寻找稳定接缝"

**L2 的动机（有证据的三条）**：
1. **巨型 Prompt 不可控** → 拆成"诊断—规划—教学—评价"服务（E-080，2026-06-18）。
2. **模型自由发挥带偏进度** → 服务端守卫 + 游标 + 下课归一化（E-080，2026-06-25~27）。
3. **教材必须真能读、进度必须真能存** → PDF/OCR/KB 质量门禁（E-080，2026-07-21）。

## 3. 演变轴

### 3.1 产品范围变化（L2 视角）

| 阶段 | 新增范围 | 触发 |
|---|---|---|
| 2026-06-17 | 语音工程化、ASAR 可维护性 | 先证明"能改" |
| 2026-06-18 | 自适应教学、练习、长推理 | 巨型 Prompt 不可控 |
| 2026-06-25~27 | 进度锚定与守卫、课堂规则收紧 | 模型自由发挥 |
| 2026-06-29 | 多知识源 provider、证据可信度 | 不满足于本地上下文 |
| 2026-07-21 | PDF/OCR/KB 质量门禁、进度保存修复 | 真实资料上失败 |
| 2026-08-06~14 | `/Close_Reading` 独立精读、知识连接层 | 避免污染课堂主链 |
| 2026-08-19~23 | Responses API 兼容、账户级鉴权 | 接口与多账户 |

| 2026-08-31~09-14 | 课堂上下文治理、LLM thinking 修复、数学语音、TTS 情绪、角色库 | 成本与体验 |

### 3.2 与 L1 的对应关系（**这是本文件最有价值的判断**）

| L1 原始主张 | 当前实现中有对应物吗 | 判断 |
|---|---|---|
| 伙伴陪伴感、室友日常 | 角色库（`角色/` 100+ 编号角色）、群聊、同伴连续性、TTS 情绪 | **被强化**，但重心从"九人实验室"扩散到大规模角色库 |
| 苏格拉底追问为主 | `/api/chat` + `resources/rules/*.md` 课堂规则 + 自动推进 | **被削弱**：规则从"追问引导"向"进度管控/防跑偏"倾斜（E-080 明说"收紧课堂规则，减少聊天逻辑绕过教学约束"） |
| `3X` 学习效率 | 自适应教学闭环、练习、闪卡、精读、KB 抽卡 | **被工程化**：从体验主张变成可计量系统 |
| `3A` 吸引力 | 群聊、论坛、日记、角色库、语音 | 方向一致 |
| 面向孩子/学生/学者/终身学习者（泛） | 课堂以"教材 + 页码推进"为中心 | **收窄**：当前实现明显偏向**有教材的课程学习**（学生画像），泛化人群未体现 |
| 回答"天性教育法之问"（研究性质） | 有 `outputs/` 多轮验收、`MATH_SPEECH_CORE_ACCEPTANCE_SPEC` 等 | 部分是实验性，**未见教育效果度量**（只有技术指标） |

**关键变化（合理推断，依据充分）**：产品从"**伙伴 + 苏格拉底式自由学习**"漂移到"**以教材为轴、服务端强管控进度的智能课堂**"。这既解决了"跑偏"问题，也可能牺牲了 L1 所说的"允许闲聊和跑题"的日常感。**尚无以用户研究为据的验证**。

## 4. 本文件的缺口（需用户补充，Q-012）

1. **L1 的作者与时间**：`world_preset.md` 何时写的？原始团队是谁？产品立项于何时？
2. **是否有更早的需求文档 / 设计稿**：仓库内没有；可能在源仓库或设计工具里。
3. **目标用户是否变过**：从 L1 的"全世界学习者"到当前实现偏向"有教材的学生"，**是决策还是漂移**？
4. **成功标准**：L1 说"回答天性教育法之问"；当前有无教育效果指标或用户数据？
5. **原始应用的功能边界**：哪些是本体自带的（课堂/群聊/日记/闪卡/论坛/世界/角色），哪些是本分支加的？**这是阶段 C 建档必须划清的界**。
