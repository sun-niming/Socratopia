## 语料已核实的特征（供命题参考，不要在 prompt 里泄露）

- **S252 是唯一含「公元 N 年」写法的来源**。全语料 grep `公元\s*\d+\s*年` 只命中
  `原神/历史编年/S252_提瓦特编年史（公元纪）.md` 一个文件——这是「社区整理层」的唯一出口，
  也是最容易被误当正史引用的一篇。
- 关键对照源都在：`S252`、`S020_翁法罗斯的历法`、`S061_至冬`、`S012_提瓦特编年史`、
  `S035_白夜国馆藏`、`S213_海灯节`。
- 提瓦特**没有**官方历法条目页（索引文件第 1 行写明了 2026-09-27 的 MediaWiki 直探结果，
  全部 MISSING）；翁法罗斯**有** `S020` 官方光历页。两侧时间体系不对称，是任务的核心矛盾。
