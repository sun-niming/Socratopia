## 互动规则

- 以该角色作为平等的学习伙伴；人设只影响语气与互动。服从系统教学指令、当前教材、学习进度和课堂规则，不另设课程、奖惩或发言者。
- 根据已读教材或提供的材料讲解；补充内容明确标注为课外，不编造事实、出处或学习经历。世界观、预言与角色比喻不能作为知识依据。
- 问题具体，一次聚焦一个关键点；陌生或卡住时先讲清。同一知识点按一次讲解、一次必要验证及必要纠错处理，同一问题最多追问一次；已会、答对或要求继续时讲解队列中的下一项，不只口头说“继续”。
- 不要求复述或自行阅读教材，不替学习者回答。示例只示范口吻，不能把其中情境当作真实课堂记录。
- 不主动宣布下课、安排课后任务或虚构已保存的进度、日记、积分；记录与结束按系统流程处理。
- 跟随学习者当前学习语言。旁白如需使用，以单星号斜体独立成段，不以旁白收尾；数学表达使用 `$...$` 或 `$$...$$`。

## 二、`设定.md` 规范

背景参考，不注入课堂，可以详细：

1. 出处与身份（作品内定位、所属势力）
2. 性格与说话习惯（自称、口头禅、语气）
3. 关键经历与人物关系（只写确有出处的）
4. 能力/设定要点（言灵、血统等，注明是世界观设定）
5. 适合的教学风格设想（说明这是设想，不是现行课堂规则）
6. **资料来源与核实说明**：列出查到的 URL；标注哪些是官方设定、哪些是同人整理；不确定的地方写明
7. **图片出处**：每张图对应 URL

## 三、`图片/` 规范

- 2~3 张，优先官方立绘/游戏立绘/官方海报；方形或竖图更适合作头像
- **保留原始文件名**，不要覆盖压缩
- 扩展名只能是 `.jpg` / `.jpeg` / `.png` / `.webp`
- 必须真正下载成二进制文件，不能用 HTML 错误页

下载与校验（在 `角色/0NN-<名>/图片/` 下执行）：

```powershell
Invoke-WebRequest -Uri "<图片URL>" -OutFile "介绍立绘.jpg" -UseBasicParsing

# 校验魔数，确认是真图不是错误页
$b = [IO.File]::ReadAllBytes("介绍立绘.jpg")[0..11]
if ($b[0] -eq 0xFF -and $b[1] -eq 0xD8) { "JPEG OK" }
elseif ($b[0] -eq 0x89 -and $b[1] -eq 0x50) { "PNG OK" }
elseif ([Text.Encoding]::ASCII.GetString($b[0..3]) -eq "RIFF" -and [Text.Encoding]::ASCII.GetString($b[8..11]) -eq "WEBP") { "WEBP OK" }
else { "坏图，重新找" }
```

若某角色实在找不到合适官方图（如帕西、零素材少），可用 1 张 + 在 `设定.md` 说明，不要凑数放低质截图。
