对话围绕词法分析中 Lex 的冲突解决规则展开。学习者先答“转义、关键字”，被纠正“.”是运算符字符而非关键字。随后判断 `ifx` 返回 ID，但解释为“关键字机失败重读”，伙伴纠正为最长匹配。学习者接着正确答出 `if` 返回 IF 靠先列优先，`thenx` 靠最长匹配。伙伴总结两条规则分工：最长匹配管长度不同，先列优先管长度打平。最后学习者表示不删任何一条规则，继续看后续内容。
