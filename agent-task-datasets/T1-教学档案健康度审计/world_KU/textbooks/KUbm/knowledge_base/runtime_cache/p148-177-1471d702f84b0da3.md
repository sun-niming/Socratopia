### 阶段 1: 文件I/O基础调用
**[当前教学焦点]** 目标: 先建立无缓存文件I/O中定位、检测与状态标志操作的基础概念，为后续阻塞模式和加锁做铺垫。

#### lseek文件定位
lseek是无缓存文件I/O中的系统调用，用于移动文件描述符对应文件的读写位置指针。其原型为 off_t lseek(int fd, off_t offset, int whence)。其中 fd 是文件描述符，offset 是位移量，whence 指定位移的参照位置。教材给出的 whence 取值有 SEEK_SET、SEEK_CUR、SEEK_END。
要点:
- lseek用于定位文件读写指针
- whence决定offset相对于哪里计算
- SEEK_SET表示相对文件开头，SEEK_CUR表示相对当前位置，SEEK_END表示相对文件末尾
示例:
- 调用形式：lseek(fd, offset, SEEK_SET)
- 调用形式：lseek(fd, offset, SEEK_CUR)
- 调用形式：lseek(fd, offset, SEEK_END)
常见误区:
- 把lseek误认为读写数据的函数；它的作用是移动指针，不是直接完成读写
自测:
Q: lseek函数的作用是什么？
A: 用于定位文件描述符对应文件的读写位置指针。
Q: lseek中whence常见的三个取值是什么？
A: SEEK_SET、SEEK_CUR、SEEK_END。

#### access文件检测
access是用于检测文件可访问性的系统调用。教材给出的原型为 int access(char *path, int mod)。其中 path 是待检测文件的路径，mod 是测试项，可以是 R_OK、W_OK、X_OK、F_OK 之一，也可以对多个测试项按位或组合。F_OK用于检测文件是否存在。
要点:
- path表示待检测文件的路径
- mod表示检测项目
- 可检测读权限、写权限、执行权限和是否存在
- 多个检测项可以按位或组合
示例:
- access("/tmp/a.txt", F_OK) 用于检测文件是否存在
- access("/tmp/a.txt", R_OK|W_OK) 用于同时检测读写权限
常见误区:
- 认为access只能检测文件是否存在；实际上还可检测读、写、执行权限
自测:
Q: access中的F_OK表示什么？
A: 表示检测文件是否存在。
Q: access能否同时检测多个权限？
A: 可以，教材指出多个测试项可以按位或组合。

#### fcntl修改文件状态标志
fcntl可用于修改或获取文件描述符的状态标志，也可用于加锁。教材给出的形式为 int fcntl(int fd, int cmd[, flags|lockType])。在状态标志相关操作中，fd 是文件描述符，cmd 可取 F_GETFL 和 F_SETFL。F_GETFL用于获取指定描述符的状态标志；F_SETFL用于重设文件状态标志。教材列出的可重设状态标志包括 O_APPEND、O_NONBLOCK、O_ASYNC。
要点:
- fcntl既可处理状态标志，也可处理锁
- F_GETFL用于获取状态标志
- F_SETFL用于设置状态标志
- 教材列出可设置的标志有O_APPEND、O_NONBLOCK、O_ASYNC
示例:
- 先用fcntl(fd, F_GETFL, ...)获取flags
- 再修改flags后用fcntl(fd, F_SETFL, flags)写回
常见误区:
- 把fcntl只看成加锁函数；教材明确指出它也能获取和重设状态标志
自测:
Q: fcntl中F_GETFL和F_SETFL分别做什么？
A: F_GETFL获取文件描述符状态标志，F_SETFL重设文件状态标志。
Q: 教材列出的F_SETFL可设置的状态标志有哪些？
A: O_APPEND、O_NONBLOCK、O_ASYNC。

可延伸方向: 可延伸到open的flags概念; 可补充文件描述符基础
