#### 无名管道流程
无名管道用于进程间通信时，一般先创建所需管道，再生成一个或多个子进程；随后把相关文件描述符复制并与相应的管道端对应起来，关闭不需要的管道端，进行通信活动，最后关闭所有剩余的打开文件描述符。
要点:
- 无名管道的使用不是单一步骤，而是“创建—派生进程—整理文件描述符—通信—收尾”的完整流程。
- 必须关闭不需要的管道端，否则会影响正确通信。
- 通信结束后应关闭所有剩余文件描述符。
示例:
- 先创建管道，再 fork 出子进程；父进程保留写端，子进程保留读端，完成类似 cmd1 cmd2 的管道通信。
常见误区:
- 以为只要创建了管道就能直接通信；实际上还必须生成进程并正确处理文件描述符。
- 以为管道两端都可以一直不关闭；不关闭无用端会干扰通信结束判定。
自测:
Q: 无名管道进行进程间通信的步骤有哪些？
A: 创建管道、生成子进程、复制/关闭文件描述符并与管道端对应、关闭不需要的管道端、进行通信、关闭所有剩余文件描述符。

#### popen与pclose
popen(char *cmd, char *type) 用于创建一个管道并 fork 子进程，在子进程中 exec 一个 shell 执行指定命令，然后等待命令终止；type 取 r 或 w，表示以读或写方式打开。成功时返回一个文件流指针，失败返回 NULL。pclose(FILE *stream) 用于关闭 popen 打开的文件流。
要点:
- popen 会创建管道并启动子进程执行命令。
- type 只能取 r 或 w，表示读或写方向。
- pclose 用于关闭 popen 返回的流。
- 头文件是 stdio.h。
示例:
- popen("ls -l", "r") 可用于从命令输出中读取数据。
常见误区:
- 以为 popen 只是普通文件打开；实际上它会执行命令。
- 以为 pclose 只是关闭文件描述符；它是关闭 popen 创建的文件流。
自测:
Q: popen 的作用是什么？
A: 它创建管道并 fork 子进程，在子进程中通过 shell 执行指定命令；返回可读或可写的文件流指针。
Q: pclose 的作用是什么？
A: 关闭 popen 打开的文件流。
