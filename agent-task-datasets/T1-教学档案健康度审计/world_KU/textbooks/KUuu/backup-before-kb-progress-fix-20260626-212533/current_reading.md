## 教学地图（第 285-307 页）

### 阶段 1: 原型机制基础
**[当前教学焦点 / 队列起点]** 目标: 让学习者理解 JavaScript 对象如何通过原型和原型链共享、查找属性与方法。

#### 原型与[[Prototype]]
JavaScript 是一种基于原型的语言。每个对象都有一个指向其原型对象的内部指针 [[Prototype]]，对象可以通过这个指针访问原型对象上的属性和方法。每个函数都有一个 prototype 属性，该属性指向一个对象，这个对象就是该函数作为构造函数时所使用的原型对象。使用 new 关键字创建实例对象时，实例对象的 [[Prototype]] 会自动设置为构造函数的 prototype。
要点:
- 对象有内部指针 [[Prototype]] 指向原型对象。
- 函数有 prototype 属性，指向其原型对象。
- new 创建实例时，实例的 [[Prototype]] 指向构造函数的 prototype。
- 示例关系：Foobar.prototype === Object.getPrototypeOf(new Foobar)。
示例:
- Foobar.prototype === Object.getPrototypeOf(new Foobar)
常见误区:
- 误以为 prototype 是每个对象都有的属性；原文强调每个函数有 prototype，而对象有内部指针 [[Prototype]]。
- 误以为实例对象复制了构造函数 prototype 上的所有属性；实际上实例通过 [[Prototype]] 指向原型对象并访问其中成员。
自测:
Q: 使用 new Foobar 创建对象时，新对象的 [[Prototype]] 指向哪里？
A: 指向构造函数 Foobar 的 prototype 属性所指向的原型对象。
Q: Foobar.prototype 与 Object.getPrototypeOf(new Foobar) 的关系是什么？
A: 二者相等，即 Foobar.prototype === Object.getPrototypeOf(new Foobar)。

#### 原型链
每个实例对象都有一个私有属性 __proto__ 指向其构造函数的原型对象 prototype。该原型对象也有自己的原型对象 __proto__，如此层层向上连接，直到某个对象的原型对象为 null。null 没有原型，是原型链的最后一个环节。原型链解释了为什么一个对象能够拥有或访问定义在其他对象中的属性和方法。
要点:
- 实例对象的 __proto__ 指向构造函数的 prototype。
- 原型对象也可以继续有自己的原型对象。
- 原型链最终到达 null。
- null 没有原型，是原型链的终点。
- 对象能访问其他对象中的属性和方法，是由原型链机制解释的。
示例:
- 一个实例对象 object 的 __proto__ 指向构造函数的 prototype；该 prototype 的 __proto__ 又继续指向上一层原型对象，直到 null。
常见误区:
- 误以为原型链可以无限向上查找；实际上最终会到达 null。
- 误以为 null 也是某个构造函数的实例；原文说明 null 没有原型，并作为原型链最后环节。
自测:
Q: 原型链的最后一个环节是什么？
A: null，因为 null 没有原型。
Q: 原型链用来解释什么现象？
A: 解释为什么一个对象会拥有或访问定义在其他对象中的属性和方法。

#### 原型扩展
原型扩展是指通过“构造函数.prototype.扩展属性 = 属性值”的方式，把属性或方法添加到构造函数的原型对象上。由此构造函数产生的所有对象都将拥有或能够访问该属性。属性值可以是函数，因此常用于给实例共享方法。
要点:
- 语法形式：构造函数.prototype.扩展属性 = 属性值。
- 属性值可以是函数。
- 通过该构造函数创建的所有对象都将拥有或访问该扩展属性。
- 原型扩展适合定义实例共享的属性或方法。
示例:
- 构造函数.prototype.扩展属性 = 属性值（可以是函数）
常见误区:
- 误以为只会影响某一个实例；原文指出此构造函数产生的所有对象都将拥有该属性。
- 误以为扩展属性只能是普通值；原文指出属性值可以是函数。
自测:
Q: 如何在构造函数的原型上扩展属性？
A: 使用“构造函数.prototype.扩展属性 = 属性值”的形式。
Q: 把函数赋值给构造函数.prototype 上的属性有什么效果？
A: 该函数可作为此构造函数所产生对象共享的方法。

#### 属性查找规则
当对象访问一个属性时，JavaScript 会先检查该对象自身是否有这个属性；如果没有，就查找该对象的原型对象；如果原型对象上也没有，就继续查找原型对象的原型对象，直到原型为空。如果在查找过程中找到该属性，就返回该属性值；如果一直找不到，就返回 undefined。
要点:
- 属性查找先从对象自身开始。
- 自身没有时，沿原型对象逐层向上查找。
- 查找到原型为空时停止。
- 找到属性则返回对应属性值。
- 找不到则返回 undefined。
示例:
- 访问 obj.x 时：先查 obj 是否有 x；没有则查 obj 的原型对象；再没有则继续向上查；若最终没有找到，则返回 undefined。
常见误区:
- 误以为访问属性只检查对象自身；实际上会沿原型链继续查找。
- 误以为没有属性时一定报错；原文说明找不到时返回 undefined。
自测:
Q: 对象访问某属性但自身没有时会怎样？
A: 会查找它的原型对象上的该属性，如果还没有则继续沿原型链查找。
Q: 沿原型链查找属性最终未找到时返回什么？
A: 返回 undefined。

### 阶段 2: 从原型到类
**[后续教学队列]** 目标: 让学习者理解 ES6 class 是建立在原型之上的对象创建语法，并掌握类的基本结构。

#### 构造器与原型方法模式
常见的对象定义模式是：在构造器函数体中定义属性，并且需要使用 this 对象来定义；在构造函数的 prototype 属性上定义方法。这样构造器只包含属性定义，而方法封装在不同的代码块中，代码更具可读性。
要点:
- 构造器函数体中定义属性。
- 定义属性时需要使用 this 对象。
- 方法定义在 prototype 属性上。
- 构造器只包含属性定义，方法放到其他代码块中，可以提升可读性。
示例:
- 构造器中写 this.name = ... 这类属性定义；在 构造函数.prototype 上定义方法。
常见误区:
- 误以为方法必须写在构造器函数体内部；原文推荐在 prototype 属性上定义方法。
- 误以为 this 可以省略；原文指出构造器中定义属性需使用 this 对象。
自测:
Q: 常见对象定义模式中，属性和方法分别放在哪里？
A: 属性放在构造器函数体中并用 this 定义，方法放在构造函数的 prototype 属性上。
Q: 把方法定义在 prototype 上有什么代码组织上的好处？
A: 构造器只包含属性定义，方法封装在不同代码块中，代码更具可读性。

#### 类的概念与基本语法
类是用于创建对象的模板，用代码封装数据以对其进行处理。JavaScript 中的类建立在原型之上，同时具有一些类独有的语法和语义。在 ES6 中，class 提供了更简洁、更直观的语法来定义对象，并提供继承和其他面向对象编程特性。class 的基本元素包括 class 关键字、类名、构造函数、方法等；语法上，class 可以看作一种特殊类型的函数。
要点:
- 类用于创建对象，是对象的模板或蓝图。
- 类用代码封装数据以便处理。
- JavaScript 的类建立在原型之上。
- ES6 的 class 提供更简洁、直观的对象定义语法。
- class 基本元素包括 class 关键字、类名、构造函数和方法。
- 语法上 class 可看作一种特殊类型的函数。
示例:
- class 类名 { constructor(...) { ... } 方法名(...) { ... } }
常见误区:
- 误以为 JavaScript 的类完全脱离原型机制；原文说明 JS 中的类建立在原型之上。
- 误以为 class 只是普通对象；原文说明语法上 class 可以看作特殊类型的函数。
自测:
Q: JavaScript 中类的作用是什么？
A: 类是用于创建对象的模板，用代码封装数据以对其进行处理。
Q: ES6 中 class 的基本元素有哪些？
A: class 关键字、类名、构造函数、方法等。

#### constructor构造函数
constructor 是类中的特殊方法，在创建新对象时会自动调用。它的作用是初始化对象的状态，或者执行其他必要操作。类中构造函数的方法名固定为 constructor。
要点:
- constructor 是类中的特殊方法。
- 创建新对象时 constructor 会自动调用。
- constructor 用于初始化对象状态。
- constructor 也可执行创建对象时需要的其他操作。
- 构造函数名固定为 constructor。
示例:
- class Person { constructor(name) { this.name = name; } }
常见误区:
- 误以为构造函数名称可以随意命名；原文说明函数名固定为 constructor。
- 误以为 constructor 需要手动普通调用才会执行；原文说明创建新对象时会自动调用。
自测:
Q: 类中的 constructor 什么时候被调用？
A: 在创建新对象时自动调用。
Q: constructor 的主要作用是什么？
A: 初始化对象状态，或者执行其他必要操作。

#### 类声明与类表达式
类实际上是“特殊的函数”。类似函数可以用函数声明和函数表达式定义，类也有两种定义方式：类声明和类表达式。
要点:
- 类实际上是特殊的函数。
- 类有两种定义方式。
- 第一种是类声明。
- 第二种是类表达式。
示例:
- 类声明：class A { }；类表达式：const A = class { }。
常见误区:
- 误以为类只能用 class 类名 的声明形式定义；原文说明类也可以用类表达式定义。
自测:
Q: 类有哪两种定义方式？
A: 类声明和类表达式。
Q: 为什么类的定义方式可以类比函数？
A: 因为类实际上是“特殊的函数”，类似函数声明和函数表达式，类也有类声明和类表达式。
