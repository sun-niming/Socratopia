### 阶段 6: 缓冲区与输入输出协同
**[当前教学焦点 / 队列起点]** 目标: 最后讲解输入输出系统中的缓冲区如何通过信号量和四种工作方式支持进程协同。

#### 缓冲区队列的互斥与同步
在缓冲池中，每一队列既是临界资源，又需要让生产者和消费者按顺序协同工作。因此，对缓冲池中的每个队列设置两个信号量：互斥信号量 $MS(type)$ 用于保证进程互斥访问队列，资源信号量 $RS(type)$ 用于保证进程同步使用缓冲区。对队列的操作通过 Getbuf 和 Putbuf 过程完成。
要点:
- 缓冲池中的队列本身是临界资源，访问时既要互斥又要同步。
- $MS(type)$ 用于互斥访问队列，$RS(type)$ 用于同步缓冲区资源。
- 对缓冲池中的队列进行操作使用 Getbuf 和 Putbuf 过程。
示例:
- Getbuf(type): $$\begin{aligned} &Wait(RS(type));\\ &Wait(MS(type));\\ &B(number)=Takebuf(type);\\ &Signal(MS(type));\\ \end{aligned}$$
- Putbuf(type, number): $$\begin{aligned} &Wait(MS(type));\\ &Addbuf(type, number);\\ &Signal(MS(type));\\ &Signal(RS(type));\\ \end{aligned}$$
常见误区:
- 只设置互斥信号量就足够了，实际上还要考虑同步。
- 资源信号量和互斥信号量是同一个作用。
自测:
Q: 为什么缓冲池队列要同时设置互斥信号量和资源信号量？
A: 因为队列既是临界资源，多个进程访问时必须互斥；又要保证进程按缓冲区的可用情况同步，因此需要两个信号量分别完成这两种控制。

#### 缓冲区四种工作方式
缓冲区在输入/输出处理中可以处于四种工作方式：收容输入、提取输入、收容输出、提取输出。不同方式对应不同进程对缓冲区的使用顺序：先从空缓冲队列取出缓冲区使用，装满后挂入相应工作队列；或者从工作队列取出已装满的缓冲区使用，用完后再放回空缓冲队列。
要点:
- 四种方式分别是：收容输入、提取输入、收容输出、提取输出。
- 输入进程和输出进程都通过 Getbuf / Putbuf 在空缓冲队列与工作队列之间转移缓冲区。
- 缓冲区使用完后要归还到空缓冲队列 emq。
示例:
- 收容输入：输入进程先调用 $Getbuf(emq)$ 取得空缓冲区 $hin$，输入数据并装满后，再调用 $Putbuf(inq, hin)$。
- 提取输入：计算进程调用 $Getbuf(inq)$ 得到 $sin$，提取数据后再调用 $Putbuf(emq, sin)$。
- 收容输出：计算进程调用 $Getbuf(emq)$ 得到 $hout$，装满输出数据后调用 $Putbuf(outq, hout)$。
- 提取输出：输出进程调用 $Getbuf(outq)$ 得到 $sout$，取出数据后再调用 $Putbuf(emq, sout)$。
常见误区:
- 缓冲区只能用于输入或只能用于输出。
- 缓冲区一旦被某进程取走就不再返回空缓冲队列。
自测:
Q: 缓冲区的四种工作方式分别是什么？
A: 收容输入、提取输入、收容输出、提取输出。
Q: 输入进程在收容输入方式下，先后做什么？
A: 先从空缓冲队列 emq 用 Getbuf 取出空缓冲区作为 hin，装满数据后再用 Putbuf(inq, hin) 挂入输入队列。
