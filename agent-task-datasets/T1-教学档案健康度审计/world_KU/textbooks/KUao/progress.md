p.239-171 | JavaScript 数据类型与 `typeof`
这一段主要围绕 JavaScript 基本类型、引用类型和 `typeof` 的粗分边界展开。学习者先把“Object 可以被引用，并且复合使用前面所有内容”说出来，方向接近但把“对象本体”和“引用”混在了一起；随后在提示下明确了变量里存的是**引用**，对象本身是结构。`typeof` 这条线推进得比较完整：他先理解 `typeof` 是粗分类型的工具，但在 `typeof []` 上误以为会有单独结果，被纠正为数组也归到 `"object"`；接着又主动确认 `typeof null` 是否真是 `"object"`，这一点最终被钉牢。`typeof undefined` 一开始答成 `"object"`，后来纠正为 `"undefined"`；`typeof true` 答对为 `"boolean"`。最后他拿教材表述来核对 `null` 的类型说法，说明已经开始会主动检查边界，而不是只记口诀。下一步可顺着运算符和表达式继续。
