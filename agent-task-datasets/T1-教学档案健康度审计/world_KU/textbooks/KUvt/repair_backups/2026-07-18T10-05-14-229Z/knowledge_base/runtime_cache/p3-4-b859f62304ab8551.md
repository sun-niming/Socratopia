#### 《C++20高级编程（第5版）》的书名与作者
该教材的英文书名为《Professional C++, Fifth Edition》，中文书名为《C++20高级编程（第5版）（上下册）》，作者是 Marc Gregoire（马克·格雷戈勒）。书名中的“C++20”表明本书围绕 C++20 版本展开。
要点:
- 英文书名是《Professional C++, Fifth Edition》。
- 中文书名是《C++20高级编程（第5版）（上下册）》。
- 作者是 Marc Gregoire（马克·格雷戈勒）。
- 教材内容定位为 C++20。
示例:
- 书目信息可写为：Marc Gregoire，《Professional C++, Fifth Edition》；中文书名为《C++20高级编程（第5版）（上下册）》。
常见误区:
- “第五版”不是 C++ 语言的版本号，而是该书的版本；“C++20”才是书中对应的 C++ 标准版本。
- 作者名 Marc Gregoire 与中文译名“马克·格雷戈勒”指同一人。
自测:
Q: 《C++20高级编程（第5版）》的英文书名和作者分别是什么？
A: 英文书名是《Professional C++, Fifth Edition》，作者是 Marc Gregoire（马克·格雷戈勒）。
Q: 书名中的“第五版”和“C++20”分别表示什么？
A: “第五版”表示教材的版本；“C++20”表示教材围绕的 C++ 语言标准版本。
